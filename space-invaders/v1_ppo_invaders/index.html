Two scores. The window number is one finished capture-window game (greedy, raw ALE points). The training curve is the mean of eight exploring games the learner updates on. The CNN never sees the point value — it sees +1 / 0 / −1 per frame.

The loop

Nothing is scripted. The same weights drive the window and the eight training games. After each batch of 128 steps × 8 envs (~1,024 env steps), PPO nudges the CNN so actions that led to higher return become a little more likely.

Entropy — how sure the policy is

Uniform random over 6 actions sits near 1.79 nats. Falling toward ~0.7 means favorite moves (usually move + fire) without freezing into one script. Clipfrac on this snapshot: 0.198.
